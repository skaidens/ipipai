Система управления библиотекой
Простая система управления библиотекой, реализованная в рамках учебного/ pet-проекта.

Описание
Данный проект представляет собой систему управления библиотекой, которая позволяет работать с основными сущностями библиотеки и выполнять базовые операции поиска и фильтрации.

Сущности:
Книга — содержит информацию о названии, годе издания и авторе книги.
Автор — содержит данные об авторе (имя, фамилия и прочая информация).
Читатель — содержит информацию о читателе библиотеки.

Возможности
Реализованы следующие операции:
Поиск книг по автору — позволяет найти все книги конкретного автора.
Фильтрация книг по году издания — позволяет выбрать книги, изданные в указанном году или в заданном диапазоне лет.
